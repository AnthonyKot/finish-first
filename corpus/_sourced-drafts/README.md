# Sourced drafts (pre-rewrite archive)

These are the original source-backed essays as generated against the local PDFs, kept
verbatim. They are the only place the **fine-grained** page receipts survive:
`corpus/<slug>/structure.tsv` maps chapters, but the section-level locators
(e.g. "The 'Out-of-Context' Trap, PDF pp. 423-425") exist only in this prose.

The published essays in `essays/` were rewritten for a general reader and no longer
carry inline citations. Use these drafts to re-verify any book-specific claim, or to
rebuild a citation if one is ever challenged.

Three citation formats appear across the drafts:

- `[Receipt: Chapter 15, PDF pp. 417-434; printed pp. 399-416.]`
- inline `(printed pp. 329-332 / PDF pp. 352-355)`
- a trailing `## Receipts` list

Do not publish these files; they are an editorial record, not reader-facing.
